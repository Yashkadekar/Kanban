Connect to Supabase

Your board data will be stored in a real PostgreSQL database — free, fast, and persistent. This is a one-time setup. Your keys are saved in your browser only.

1
Go to supabase.com and create a free project
2
Go to Project Settings → API and copy your Project URL and anon public key
3
Go to SQL Editor and run this to create the table:
CREATE TABLE kanban_board ( id serial PRIMARY KEY, board_key text UNIQUE NOT NULL, cards jsonb NOT NULL DEFAULT '[]', updated_at timestamptz DEFAULT now() );
